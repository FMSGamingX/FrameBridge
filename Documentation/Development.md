# Developing FrameBridge

Created by Faris Alsari / FMSGaming · Famous Gaming

Use main for tested stable revisions and develop for integration. Start experimental work on develop or a feature branch derived from it. Build locally with the pinned LLVM toolchain and test with the commands in [Build.md](Build.md).

Before committing, review the staged changes, synchronize documentation and record which hardware and inputs ran. Keep credentials, PS5 registration material, models, machine preferences, compiled executables, drivers and test recordings outside the repository. Review both the staged file list and the history reachable by each branch before the first push.

Fetch and inspect remote branch tips before pushing. Use normal fast-forward pushes or reviewed merges. Publish releases only with Faris's approval. Keep FrameBridge private until the owner decides on licensing and publication.
